# Frontend visual adaptation

The V1 consult workspace adapts the following read-only legacy Lamina elements:

- Warm parchment background (`#f7f3ec`) and ivory surfaces (`#fffcf7`).
- Rust primary action, deep clinical navy, muted sage status, soft gray-brown borders, and near-black copy.
- Lora-style serif display typography paired with Inter-style UI typography.
- The cropped Lamina network mark and uppercase wordmark treatment.
- A quiet left navigation shell, top-rule cards, compact uppercase labels, 1 px borders, 9–16 px radii, and soft navy shadows.
- Restrained status badges, progress dots, and loading treatments rather than simulated conversations.

The structure is new and product-specific: Specialty Care Consult context, referring clinician, coverage, consult reason, longitudinal renal trajectory, Consult Network action, and an inspectable recommendation. No legacy feed or forum components are reused.
